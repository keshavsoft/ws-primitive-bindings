What is ws-primitive-bindings?

ws-primitive-bindings is a dedicated wiring layer for WebSockets in web applications. It replaces monolithic onmessage and switch(data.type) handlers with clean, serializable JSON blueprints (bindings.json) mapped to isolated action functions (actions.js).

It features automatic safe JSON decoding, message type filtering, event grouping, and strict runtime guards.

import { bindWs } from "ws-primitive-bindings";
import bindings from "./bindings.json" with { type: "json" };
import actions from "./actions.js";

const socket = new WebSocket("ws://localhost:3000/ws");
bindWs(socket, bindings, actions);
