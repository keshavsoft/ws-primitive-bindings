The 3-File Architecture for WebSockets

Blueprint (JSON) + Actions (JS) + Orchestrator (bindWs).

Story Hub

The Three Standard Files

1. bindings.json

Defines socket events (`open`, `message`, `error`, `close`) and optional message `type` filters.

2. actions.js

Pure callback functions receiving `(payload, event, ws)`. No socket listener loops.

3. index.js

Instantiates the socket and invokes `bindWs(socket, bindings, actions)`.
