The Declarative Transformation

Instead of writing large switch or if/else chains in code, you define your WebSocket event and message type routes in a simple bindings.json: 

// bindings.json
[
  { "event": "open", "action": "onConnected" },
  { "event": "message", "type": "state", "action": "onStateUpdate" },
  { "event": "message", "type": "announcement", "action": "onNewAnnouncement" },
  { "event": "error", "action": "onError" },
  { "event": "close", "action": "onClosed" }
]

The engine takes care of safe JSON decoding, checks the type field, and calls the exact matching action function directly.
