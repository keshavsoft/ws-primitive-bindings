Distribution & Quick Start

Usage & Available Builds

Zero dependencies. Drop into any HTML client via ESM import, script tag, or npm package.

Browser Script Tag (CDN)

Load globally as a module in any HTML page:

<script type="module" src="https://keshavsoft.github.io/ws-primitive-bindings/dist/v1/min.js"></script>
import { bindWs } from "https://keshavsoft.github.io/ws-primitive-bindings/dist/v1/min.js";

NPM Package Installation

Install in bundled Node/Vite projects:

npm install ws-primitive-bindings
